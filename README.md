# :computer: SkinHerbCare-WebApplication
ระบบเว็บแอปพลิเคชันที่พัฒนาเพื่อช่วยวิเคราะห์โรคผิวหนังเบื้องต้น และแนะนำสมุนไพรไทยที่เหมาะสมสำหรับการรักษา โดยใช้เทคโนโลยีปัญญาประดิษฐ์ (AI) และ Deep Learning ระบบถูกพัฒนาขึ้นเพื่อผสาน ภูมิปัญญาสมุนไพรไทย เข้ากับ เทคโนโลยีสมัยใหม่ เพื่อช่วยให้ผู้ใช้สามารถเข้าถึงข้อมูลโรคผิวหนังและสมุนไพรได้ง่ายขึ้น และช่วยสนับสนุนการศึกษาและการวิจัยด้านแพทย์แผนไทย
ระบบสามารถทำงานได้ผ่านเว็บแอปพลิเคชัน และรองรับการใช้งานบน คอมพิวเตอร์ แท็บเล็ตและสมาร์ตโฟน

# :pushpin: System Features
## :busts_in_silhouette: นิสิตแพทย์แผนไทย/ผู้ใช้ทั่วไป

1. ฟังก์ชันการวิเคราะห์รูปโรคผิวหนัง
  - อัปโหลดภาพผิวหนังที่มีรอยโรค
  - ระบบ AI วิเคราะห์ภาพ
  - แสดงผลชื่อโรคและสมุนไพรที่แนะนำ
รองรับโรคผิวหนังพื้นฐาน คือ กลาก สิว งูสวัด เริม ลมพิษ สะเก็ดเงิน ด่างขาว

2. ฟังก์ชันค้นหาข้อมูลจากรูปสมุนไพร
  - ถ่ายภาพสมุนไพร
  - ระบบจะตรวจจับชนิดสมุนไพร
  - แสดงข้อมูลสมุนไพร เช่น สรรพคุณ วิธีใช้ และโรคที่สามารถรักษาได้
รองรับข้อมูลสมุนไพร 12 ชนิด คือ ขมิ้น เปลือกมังคุด ว่านหางจรเข้ กระเพรา แตงกวา พญายอ พลูคาว พลู โหระพา ข่า กระเทียม ตำลึง

3. ฟังก์ชันวิเคราะห์จากอาการที่พิมพ์
  - พิมพ์อาการ เช่น คัน มีตุ่มแดง มีแผลพุพอง
  - ระบบจะวิเคราะห์อาการด้วย AI
  - คาดการณ์โรคที่เป็นไปได้
  - แนะนำสมุนไพรที่เหมาะสม

# :mega: Technologies Used
## Machine Learning
1. YOLOv8 สำหรับตรวจจับและจำแนกสมุนไพรจากภาพ
2. MASK R-CNN สำหรับตรวจจับและจำแนกโรคผิวหนังจากภาพ
3. RAG AI สำหรับวิเคราะห์โรคผิวหนังจากอาการที่พิมพ์

## Programming Languages
Python , JavaScript , HTML , CSS

# :page_with_curl: How to uses
1. ลงทะเบียนหรือลงชื่อเข้าใช้งาน
2. เลือกเมนูที่ต้องการ แล้วทำตามขึ้นตอน
   - ค้นหาสมุนไพรจากภาพ -> อัปโหลดภาพสมุนไพร -> กดวิเคราะห์ 
   - วิเคราะห์โรคผิวหนังจากภาพ -> อัปโหลดภาพบริเวณที่เกิดโรค -> กดวิเคราะห์
   - วิเคราะห์โรคจากอาการ -> พิมพ์อาการที่เกิดขึ้น เช่น มีอาการปวดแสบปวดร้อน
